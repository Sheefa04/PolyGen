# PolyGen

Interactive 3D Asset Creation and Customization Studio.

## Project Goal
To create a browser-based application that allows
users to generate and customize supported 3D assets
using text prompts.

## Initial Features
1. Text-to-3D procedural asset creation.
2. Interactive 3D model viewer.
3. Colour and dimension customization.
4. Add and remove object components.
5. Small 3D scene builder.
6. GLB model export.

## Proposed Technologies
- Python
- FastAPI
- React
- TypeScript
- Three.js
- SQLite

## AI Usage
AI may help interpret natural-language prompts.
Procedural geometry will create the initial 3D assets.
